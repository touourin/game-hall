# 手机对局与多人入口 UX 改造记录

记录日期：2026-08-03  
状态：核心改造已完成；象棋竖屏、横屏与多人入口已完成模拟验收

## 一、iPhone 真机问题

测试设备为 iPhone 15 Pro Max。象棋棋盘的九列十行、棋子位置、楚河汉界和走棋交互本身正常，问题主要来自手机对局页的信息架构与浮动组件：

- 开局后仍先展示完整玩家信息、房间规则和协商区域，重新进入对局时棋盘可能落到首屏以下。
- 悬浮聊天按钮使用固定定位，会在部分滚动位置遮挡复盘、导出、认输等操作。
- Safari 动态地址栏会改变可视高度；页面仍有 `100vh` 布局，未完全使用 `dvh/svh`。
- 320–360px 窄屏下，九列棋盘的单个落点较小，需要使用“点击坐标吸附到最近交叉点”提升触控容错。
- 手机皮肤选择器横向展示约 1.8 张卡片；滚动到最后一项时左侧出现半张卡片，视觉上像被裁切。
- 等待区固定 `min-height: 390px`，与玩家、规则、皮肤和邀请区域纵向叠加后页面过长。

## 二、推荐的通用手机对局结构

不要按 iPhone 或安卓型号分别增加断点，而应建立按可用空间和对局阶段变化的 `MobileGameShell`：

1. 等待阶段保留玩家、规则、邀请和皮肤设置，但使用紧凑卡片；开始按钮进入底部安全操作栏。
2. 开局后进入“棋盘优先模式”：紧凑状态、被吃棋子、棋盘、操作栏依次出现；玩家与房间规则折叠到棋盘之后。
3. 手机端取消覆盖内容的悬浮聊天按钮，把聊天与悔棋、和棋、认输放进统一操作栏。
4. 棋盘同时受可用宽度和 `100dvh` 可用高度约束，兼顾竖屏、横屏及 Safari 地址栏展开/收起。
5. 皮肤入口改为“当前皮肤摘要＋更换”，点击后在底部面板以一列或两列显示全部皮肤。
6. 窄屏通过最近交叉点吸附、扩大选中反馈和合法落点反馈提高触控准确度，不强制放大棋盘产生横向滚动。

建议首先接入象棋，再复用到五子棋、围棋和军旗。

## 三、多人游戏入口现状

单人游戏入口已由 `SoloChallengeLauncher` 重做为高级挑战控制台；多人游戏仍使用通用的房间列表、创建/加入分段按钮和纵向规则表单。多人入口功能完整，但与单人入口存在明显的视觉完成度差距。

多人入口建议新增共享的 `MultiplayerMatchLauncher`，概念为“对局中枢”：

- 桌面端采用“游戏氛围与在线房间 / 创建加入控制台”双栏结构。
- 手机端采用紧凑游戏头图、公开房间列表和底部主操作区。
- 创建房间先显示关键规则摘要，完整规则通过抽屉或底部面板编辑，避免长表单直接铺满页面。
- 加入房间提供突出的邀请码输入和公开房间快捷加入。
- 未结束房间使用高优先级返回对局卡，不与普通房间混在一起。
- 阿瓦隆、五子棋、象棋、围棋、德州扑克、斗地主和军旗共享结构，通过配置提供各自的强调色、文案、座位信息和规则摘要。
- 高级感来自清晰层级、空间、材质和状态反馈，不照搬单人游戏的科技控制台外观。

## 四、实施结果

本轮已完成以下改造：

- 进行中的棋盘游戏切换为棋盘优先顺序，玩家列表与房间规则移到棋盘之后。
- 手机聊天入口回到页面文档流，不再固定悬浮遮挡复盘、导出或认输操作；聊天面板使用动态视口高度。
- 象棋竖屏按可用宽度和 `dvh` 共同限制棋盘尺寸，状态、被吃棋子与操作按钮改为紧凑布局。
- 低高度横屏使用双栏布局：局面信息与操作位于左侧，完整棋盘位于右侧；窄横屏房间头保持单行。
- 手机皮肤选择改为“当前皮肤摘要＋底部选择面板”，避免横向卡片出现半张裁切。
- 等待区取消手机端固定最小高度，缩短未开局房间页面。
- 新增共享 `MultiplayerMatchLauncher`，七款多人游戏统一使用高级对局中枢，同时保留各自强调色、房间状态和规则摘要。
- 多人入口桌面端使用双栏结构，手机端自动切换单栏；完整规则通过弹层或底部面板编辑。

模拟验收结果：

- `430×932`（iPhone 15 Pro Max 竖屏）：棋盘完整进入首屏，无横向滚动，聊天不遮挡操作。
- `360×800`（窄屏竖屏）：棋盘完整显示，无横向滚动。
- `932×430`（iPhone 15 Pro Max 横屏）：完整棋盘进入首屏，信息与操作双栏排列。
- `667×375`（小尺寸横屏）：完整棋盘进入首屏，无横向滚动。
- 多人入口在 `430px` 手机宽度下无横向溢出，创建、加入、公开房间、返回未结束对局和规则编辑功能均保留。

仍建议在真实 iPhone Safari、iOS Chrome 与安卓 Chrome 上各完成一轮动态地址栏、字体放大和触控回归。iOS Chrome 与 Safari 使用同一 WebKit 内核，因此本轮修复按可用空间生效，不依赖浏览器名称。
